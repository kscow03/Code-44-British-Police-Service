How This Works

This dashboard does not have a separate student list. It reads the same aru_recruits table used by the Recruit Tracker.

When a trainer adds a student, changes a module, changes a status or updates a cohort in the Recruit Tracker, this dashboard automatically reflects the change.

That means every trainer is looking at the same live Academy information rather than separate copies.
