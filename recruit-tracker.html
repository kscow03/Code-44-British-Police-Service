Each recruit record shows their current Academy stage, overall module progression and trainer notes.

How Progress Works

The module number recorded against a student represents the stage they are currently working on.

For example, a student recorded as being on Module 4 will show Modules 1–3 as complete, Module 4 as current and Modules 5–13 as outstanding.

Once Module 13 has been passed, change the student's status to Qualified.

Data Storage Notice

This tracker uses browser local storage so that it works on a static GitHub Pages website.

The information is stored only in the browser being used. It is not automatically shared between trainers, computers or devices.

Do not use this page for genuine sensitive police information or real personal data. It is intended for Code44 Academy management only.
