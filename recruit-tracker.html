How Progress Works

The module number recorded against a student represents the stage they are currently working on.

For example, a student recorded as being on Module 4 will show Modules 1–3 as complete, Module 4 as current and Modules 5–13 as outstanding.

Once Module 13 has been passed, change the student's status to Qualified.

Shared Academy Database

Recruit information is now stored in the central Academy database rather than browser storage.

This means that when one trainer updates a recruit, the updated information can be loaded by another trainer on another computer.

Changes are saved directly to the Academy database whenever a record is added or edited.
