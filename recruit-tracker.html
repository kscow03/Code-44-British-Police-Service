How Progress Works

Each module can now be marked individually as complete.

The progress bar automatically calculates the percentage from the number of completed modules out of 13.

The next incomplete module is automatically highlighted as the current module.

Once all 13 modules are completed, the student's status can automatically move to Ready for Final Assessment.

Shared Academy Database

Recruit progression is stored centrally in Supabase rather than in browser storage.

When a trainer updates a recruit, other trainers can see the updated record from the shared database.
