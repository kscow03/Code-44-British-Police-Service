How Progress Works

Each module is tracked individually. Tick a module when the student successfully completes it.

The progress bar automatically calculates completion out of 13 modules.

Completing all 13 modules moves the student to Ready for Final Assessment.

A trainer can then manually mark the student as Qualified.

Shared Academy Database

Recruit information is stored in the central Code44 Academy Supabase database.

Changes made by trainers are saved to the database and can be seen by other trainers.

Data Storage Notice

This tracker is connected to the Code44 Academy Supabase database.

Do not enter genuine sensitive police information, passwords, real-world personal information or operationally sensitive material. This system is intended for Code44 Academy management.
