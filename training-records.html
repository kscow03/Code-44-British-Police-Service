Automatic Recruit Tracker Update

When you save a record with a PASS outcome, this page will also attempt to update the student's Recruit Tracker progression.

For example, passing Module 3 will move the recruit to Module 4 automatically. Passing Module 12 will mark them as ready for final assessment. Passing Module 13 will mark them as qualified.

Storage Notice

Training records are stored in browser local storage because the website is hosted as static GitHub Pages content.

Records are therefore available only on the browser/device where they were entered unless you later move the Academy to a shared database.

Do not store real sensitive police information or genuine personal data here.
